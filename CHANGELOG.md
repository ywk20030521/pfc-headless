### Capabilities on the current baseline

- Verified PFC2D/PFC3D Console discovery and MCP-only Run orchestration.
- Project / Case / Run management with immutable raw evidence and hashes.
- Script-embedded capture, STANDARDIZED delivery and downstream contract
  compatibility with `pfc-scientific-visualization`.
- Failure, interruption and recovery context preserved in Run records.

### Known limitations

- No formal tag or GitHub Release has been created.
- Authorization gate, Dataset-layer canonical mapping and stable feedback IDs
  are pending merge; see `docs/OPEN_SOURCE_READINESS.md`.
- Derived quantities generated by the legacy `frame_metrics` path must not be
  used as scientific results.
